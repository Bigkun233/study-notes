补充笔记

数据结构 · 队列 · 题型笔记

FIFO队列：只允许在队尾插入（入队）、队头删除（出队）的线性表。

一、循环队列的一般约定（王道口径）

数组 Q[0..n-1]，front 指向队头元素，rear 指向队尾元素的下一个位置。

约定方式队空条件队满条件元素个数
牺牲一个单元front == rear(rear+1)%n == front(rear-front+n)%n
增设 size 变量size == 0size == nsize
增设 tag 标志front==rear 且 tag==0front==rear 且 tag==1(rear-front+n)%n
口诀：牺牲单元「少用一个，满时留空」；tag 的取值为「删 0 插 1」（最近一次操作是删除→tag=0，此时 front==rear 是队空）。

二、必考题型

题型 1｜判空判满　给 front/rear 值，问队列空/满/当前元素个数。
　→ 先看约定（牺牲单元 / size / tag），再套公式；元素个数一律 (rear-front+n)%n（牺牲单元法）。

题型 2｜元素个数　count = (rear - front + n) % n。
　→ 注意 +n 不能漏，否则 rear<front 时算出负数。

题型 3｜入队/出队模拟　连续插入删除后，求此时 front/rear 与存储的元素。
　→ 画一个环形数组，指针按 (x±1+n)%n 走，最稳。

题型 4｜入队后能否再加　牺牲单元法下，最多存 n−1 个元素；问「还能入队几个」用满判据反推。

题型 5｜双端队列　输入受限/输出受限，问某序列「能否由该双端队列得到」。
　→ 逐个枚举出入顺序，抓住「两端进出」与「只能某端出」的限制。

题型 6｜队列应用　层次遍历（二叉树/BFS）、OS 缓冲区与作业调度、打印机缓冲、消息队列。
　→ 记住「先来先服务」的本质，能解释为什么用队列而非栈。

三、易错点

  • 假溢出：顺序队列不用循环时，出队后 front 后移留下的空间无法再入队 → 必须用循环队列解决。
  • 牺牲单元法的队满条件是 (rear+1)%n==front，不是 rear==front（那是队空）。
  • 链队列若带头结点，队空条件是 front==rear（都指向头结点）；不带头结点时队空是 front==NULL。
  • 入队只动 rear，出队只动 front；循环移动一律取模。
  • 元素个数公式里 -front 在前，别写成 (front-rear+n)%n。
