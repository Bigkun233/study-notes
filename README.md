## ✨ 特色

- **公式即写即排**：全站 KaTeX 渲染，数学公式清晰、可缩放（已整体放大字号，手机上也看得清）。
- **PWA / 离线可用**：Service Worker 缓存，断网也能翻；HTML 走网络优先，永远拿最新版。
- **移动端友好**：手机上打开网页即可阅读，无需安装 App。
- **考点导向**：每章按「核心定义 / 必背公式 / 常考题型 / 易错点」组织，专为刷题提分。
- **不收录**：页面带 `noindex` + `robots.txt`，仅供自己复习，不进搜索引擎。

## 📖 内容概览

### 数学二（高等数学 + 线性代数）

- **函数、极限、连续**：等价无穷小、泰勒（麦克劳林）展开、常考题型、易错点
- **一元函数微分学**：三角/反三角导数、基本导数表
- **一元函数积分学**：
  - 基本积分表、含参数的常用积分
  - **积分中值定理**（基本 / 加强 / 广义 / 第二中值定理）
  - **有理函数裂项（待定系数法）**
  - 三大方法（分部 / 换元 / 有理函数）
  - 定积分的应用（面积、旋转体体积、变上限积分）
- **多元函数微分学 / 二重积分**
- **常微分方程**
- **线性代数**：行列式、矩阵、向量、线性方程组、特征值与特征向量、二次型

### 专题 / 解题套路

- **常见不等式**（均值、绝对值、指对、伯努利、柯西、三角不等式）
- **诱导公式**（奇变偶不变，符号看象限）
- **含未知函数的定积分（设常数 A 法）** — 含 2014 北京竞赛真题两种解法

- 计算机专业基础综合考点整理（数据、组成、操作系统、网络）

## 🚀 本地预览

纯静态页面，任意静态服务器即可：

```bash
# 方式一：Python 自带
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080

# 方式二：Node
npx serve .
```

> 直接双击打开 `index.html` 也可阅读，但 PWA / 离线缓存在 `http(s)` 下才生效。
